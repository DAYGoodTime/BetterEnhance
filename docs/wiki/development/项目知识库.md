# BetterGTExperience 项目知识库

## 项目定位与事实边界

这是全新 GTNH 附属项目，根包 `com.day.betterexperience`，模组 ID `betterxeperience`。迁入的热核项目文档不代表本项目已实现功能；原知识库保存于[归档](../archive/development/迁入热核项目知识库.md)，仅用于按需追溯。

当前源码包含通用多方块基类与地狱接口复刻。基类支持普通及特殊能源输入、长整型耗电、标准配方处理、并行与超频扩展、创造／生存建造接口，默认免维护；无线支持仅保留 TODO，没有无线供电实现。地狱接口保留 TST 的原结构、随机产物机制与运行配置，并禁用原机不支持的处理选项。

## 技术与依赖

- Minecraft `1.7.10`、Forge `10.13.4.1614`，由 `gradle.properties` 声明。
- Java 使用 `jvmDowngrader` 模式，目标 Java 8；构建 JDK 见 `.java-version`。生成的 `Tags` 不手工维护。
- 保持 GTNH convention / RetroFuturaGradle；整合包依赖清单为 `2.9.0-RC-2`。运行时解析选用 GT5U `5.09.54.205`，API 已对照该版本缓存源码。
- TST 明确依赖 `0.8.0-RC2.6:dev`，加载顺序要求在 TST 之后。直接引用其结构方块、纹理、运行配置、随机池和展示配方，不复制资源、不依赖 GTNL。
- 地狱接口 Tooltip 直接复用 TST 原版语言键，再追加本项目配置、特性与结构说明；实际耗电以当前配置公式为准。源码与本地／远程仓库入口见 [TST 参考索引](../references/TST参考索引.md)。
- 开发依赖对 UniMixins、Thaumcraft 统一选择 `dev` JAR，避免 TST 元数据与其他依赖混用普通包造成重复模组；运行时解析已核验各保留一份实际 JAR。
- 旧 Thaumcraft NEI Plugin 的 CurseMaven 包通过 `runtimeOnlyNonPublishable(rfg.deobf(...))` 显式登记，将传递依赖中的 SRG 调用转换为开发环境 MCP 名称；不移除插件或改变版本。
- 开发运行依赖显式包含清单中的 BetterBuildersWands `dev` 包，补齐 CropsNH 后初始化兼容类加载所需 API；参考只读 GTNL `dependencies.gradle:54`，版本由本项目整合包清单解析。
- 开发运行依赖显式包含 Et Futurum Requiem 与 ThaumicTinkerer 的 `dev` 包，不发布为传递依赖；前者使用 GTNH Maven 的 `ganymedes01.etfuturum:Et-Futurum-Requiem:2.6.60-GTNH`，后者由当前整合包清单选版。
- 基类参考 GTNL 公共基类的职责划分与[长整型跨栈扣料思路](../references/GT-Not-Leisure参考索引.md#长整型输入消耗)。能源、NBT、生命周期及维护开关复用 GT5U，不迁入参考项目自有处理器、GUI 或生命周期改写。
- `BGTEMultiblockBase.depleteInput(ItemStack/FluidStack, long, boolean)` 为自定义配方提供跨栈精确扣料、模拟与不足不扣料，省略布尔参数即实际扣料；数量独立于模板栈大小，负数抛异常。仅在 GT 配方处理生命周期内使用，沿用普通输入集合及 ME 去重，不合并合成缓存分组；单种 ME 快照仍受 `int` 限制。多个材料的调用不构成整体事务，需由调用方先统一校验；标准配方继续复用 GT5U 的长整型总需求计算。
- 自定义并行产出先用 `long` 计算总量，再由 GT 原生 `ParallelHelper.addItemsLong/addFluidsLong` 拆分并写入输出数组；地狱接口已接入，耗水余量也使用 `long`。单栈与并行次数仍为 `int`，拆栈不提供输出空间校验；API 与数量截断陷阱见[长整型并行产出](../references/GT-Not-Leisure参考索引.md#长整型并行产出)。

## 初始化与注册

`preInit` 注册本项目 GTNHLib 配置；`init` 注册机器并绑定 `BGEMachineList`。机器 ID 经用户确认从 `32200` 开始连续递增，注册前检查范围和占用，冲突立即报错，不自动改号。

`BGEMachineList` 只保存模板副本，读取返回独立物品栈，拒绝未绑定读取、重复绑定及无效数量。当前未添加地狱接口控制器制造配方；原机组装机配方会输出 TST 控制器，与本项目注册同输入配方存在冲突，处理方式待用户确认。
