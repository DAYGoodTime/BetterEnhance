# BetterGTExperience 项目知识库

## 项目定位与事实边界

这是全新 GTNH 附属项目，根包 `com.day.betterxeperience`，模组 ID `betterxeperience`。迁入的热核项目文档不代表本项目已实现功能；原知识库保存于[归档](../archive/development/迁入热核项目知识库.md)，仅用于按需追溯。

当前源码包含通用多方块基类与地狱接口复刻。基类支持普通及特殊能源输入、长整型耗电、标准配方处理、并行与超频扩展、创造／生存建造接口，默认免维护；无线支持仅保留 TODO，没有无线供电实现。地狱接口保留 TST 的原结构、随机产物机制与运行配置，并禁用原机不支持的处理选项。

## 技术与依赖

- Minecraft `1.7.10`、Forge `10.13.4.1614`，由 `gradle.properties` 声明。
- Java 使用 `jvmDowngrader` 模式，目标 Java 8；构建 JDK 见 `.java-version`。生成的 `Tags` 不手工维护。
- 保持 GTNH convention / RetroFuturaGradle；整合包依赖清单为 `2.9.0-RC-2`。本地清单选用 GT5U `5.09.54.205`，API 已对照该版本缓存源码；新增依赖后的最终解析与编译仍待许可验证。
- TST 明确依赖 `0.8.0-RC2.6:dev`，加载顺序要求在 TST 之后。直接引用其结构方块、纹理、运行配置、随机池和展示配方，不复制资源、不依赖 GTNL。
- 基类只参考 GTNL `common/machine/multiMachineBase/MultiMachineBase.java` 的职责划分。能源、NBT、生命周期及维护开关复用 GT5U，不迁入参考项目自有处理器、GUI 或生命周期改写。

## 初始化与注册

`preInit` 注册本项目 GTNHLib 配置；`init` 注册机器并绑定 `BGEMachineList`。机器 ID 经用户确认从 `32200` 开始连续递增，注册前检查范围和占用，冲突立即报错，不自动改号。

`BGEMachineList` 只保存模板副本，读取返回独立物品栈，拒绝未绑定读取、重复绑定及无效数量。当前未添加地狱接口控制器制造配方；原机组装机配方会输出 TST 控制器，与本项目注册同输入配方存在冲突，处理方式待用户确认。
