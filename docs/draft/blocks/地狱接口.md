# 地狱接口

状态：草稿。用户已确认保留 TST 原机结构、数值与产物，机器 ID 从 32200 开始递增；控制器获取配方尚未确认。

## 用途与来源

- 控制器：`betterxeperience.nether_interface`，显示名为「地狱接口」，统一引用 `BGEMachineList.BetterTSTNetherInterface`。
- 消耗蒸馏水和电力，随机取得下界物资，产出贫瘠下界废液，并有概率产出熔融地狱金属。
- 依赖 TST，直接使用原机的机械强化黑曜石、控制器纹理、运行配置和展示配方表，不新增替代方块或流体。
- 当前未添加控制器制造配方。TST 原组装机配方仍输出其原控制器；不擅自替换其输出、注册同输入的冲突配方或新增转换配方。

## 结构与数值

- 完整保留 `TST_NetherInterface.SHAPE_MAIN` 原始字符串数组及偏移 `(7, 13, 0)`。
- 结构使用坚固机械方块、黑曜石框架、TST `MetaBlockCasing02:5` 与黑曜石；仓口要求保留原机定义。
- 运行参数直接读取 TST 配置。原版默认每轮 1200 tick、最多 64 并行；每并行消耗 16000 L 蒸馏水，耗电 `7680 × (2 + 并行)` EU/t，每轮抽取 3 份物品。
- 物品权重与单份数量：远古残骸 1×1%、重型地狱泥浆 48×49%、易碎下界合金碎片 64×30%、强键合下界合金纳米粒子 64×10%、原版指定的 Thaumic Tinkerer `kamiResource:6` 8×10%；每份物品数量乘并行。
- 废液数量等于耗水量；默认 30% 概率额外输出 `288 × 并行` L 熔融地狱金属。

## 实现边界

- 无无线供电，不支持批处理、输入分离、配方锁定或溢出保护；保留原机满输出时的行为。
- 标准 GT5U 生命周期负责进度、耗电、输入仓事务与存档；机器继承本项目公共基类。
- 保留原版权利声明；移植类遵循 GPL-3.0，发布时不能仅套用项目 MIT 模板。
- 不迁入 TST 基类新增的长整型 ME 输出队列或专用仓口功能；异常大配置的并行受物品／流体 int 容量边界限制，正常默认数值不变。
